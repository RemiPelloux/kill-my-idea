# Business plan: LunchLine

Generated by kill-my-idea:build on 2026-11-12 from the PIVOT 56/100 verdict, building fix: An Open Dental-native, HIPAA-covered AI receptionist for independent practices, $199/month with no contract, sold by missed-call audits.

The model chose the inputs; `scripts/build-kit.py` did the math. Change an input in `plan.json` and rerun the script to update every number here.

## Inputs

| Input | Value | Evidence |
|---|---|---|
| revenue per customer month | 199 | verdict metric `price` |
| variable cost per customer month | 97 | (estimate) Fix lever L1 swaps NexHealth for Open Dental write access: 450 min x $0.12 = $54 + number $2 + Open Dental $32 + card fees $6 + 10DLC $3 = $97 |
| cac | 600 | (estimate) Fix lever L2: missed-call audit hook lifts replies; ~$100 tools + ~10 h x $50 per customer |
| churn monthly pct | 6 | verdict metric `churn_monthly_pct` |
| fixed costs month | 150 | verdict metric `fixed_costs_month` |
| start cash | 2,000 | (estimate) The founder's stated budget of USD 2,000 |

Lifetime gross profit per customer: **USD 1,700** (LTV:CAC 2.8).
