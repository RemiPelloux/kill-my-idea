# Build kit: LunchLine


An AI receptionist that answers the calls a dental front desk misses and books them into Open Dental.

Verdict: **PIVOT 56/100**. Building fix: An Open Dental-native, HIPAA-covered AI receptionist for independent practices, $199/month with no contract, sold by missed-call audits.

Key metric: **Paying clinics**, 5 paying clinics at $199/month by 2027-02-28.

Base case: 14 customers and USD 2,696 MRR at month 12, break-even in month 12, cash needed USD 2,782.

## Start here

1. Read `README.md` and `docs/prd.md`.
2. `cp .env.example .env` and fill it in.
3. Sprint 0 in `docs/sprints.md`: Prove practices miss calls and will pay a $199 pilot
4. Code goes in `app/` (see `docs/architecture.md`), following `pelloux-guidelines.md`.
5. Tests with SmartTest (Node 22.12+), in `app/`: `npm install -D @tkmremi/smarttest@1.2.0`, `npx smarttest init --dry-run` then `--yes`, `npx smarttest hook install`. After that, `npx smarttest run` runs only the tests your change can affect.
6. Video and ads: `cd video && npm install && npm run video && npm run ads`.
