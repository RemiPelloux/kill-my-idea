# Motion design: Hookline Studio

Generated by kill-my-idea:build on 2026-11-11 from the PIVOT 56/100 verdict, building rescue-1: Sell a fixed monthly creative package ($1,200 for 8 ad-ready videos with hooks), not a 20% commission, to Shopify brands spending $5-30K/month on Meta ads.

Format 1080x1920, 30 fps, 24 s. Music: Upbeat, minimal electronic loop around 110 BPM from a royalty-free library, ducked under the voiceover

Render: `cd video && npm install && npm run video` writes `video/out/promo.mp4`. `npm run studio` opens it in the Remotion editor.

Motion: words spring in one by one, numbers count up, the accent bar grows, each scene fades and zooms 4% over its length. Problem and CTA scenes invert to the accent colour.
