# Build kit: Hookline Studio


8 ad-ready UGC videos a month, with the hooks written for you, for a fixed $1,200. Start with a $799 pilot of 4 videos.

Verdict: **PIVOT 56/100**. Building rescue-1: Sell a fixed monthly creative package ($1,200 for 8 ad-ready videos with hooks), not a 20% commission, to Shopify brands spending $5-30K/month on Meta ads.

Key metric: **Paid $799 pilots**, 1 or more paid pilot by day 14 by 2026-11-25.

Base case: 3 customers and USD 3,740 MRR at month 12, break-even in month 3, cash needed USD 0.

## Start here

1. Read `README.md` and `docs/prd.md`.
2. `cp .env.example .env` and fill it in.
3. Sprint 0 in `docs/sprints.md`: Run the verdict's 7-day test: 100 brands listed, 3 creators signed, offer page and payment link live, 100 cold emails sent, every positive reply asked for a paid pilot
4. Code goes in `app/` (see `docs/architecture.md`), following `pelloux-guidelines.md`.
5. Tests with SmartTest (Node 22.12+), in `app/`: `npm install -D @tkmremi/smarttest@1.2.0`, `npx smarttest init --dry-run` then `--yes`, `npx smarttest hook install`. After that, `npx smarttest run` runs only the tests your change can affect.
6. Video and ads: `cd video && npm install && npm run video && npm run ads`.
